線数字レジ MVP iPhone版

これはiPhone Safariで使うためのPWA/スマホWebアプリ版です。

重要:
- App Storeアプリではありません。
- iPhoneにホーム画面追加して使うには、HTTPSで公開されたURLからSafariで開く必要があります。
- GitHub Pages、Netlify、Vercelなどにこのフォルダの中身をアップロードして使ってください。

使い方:
1. このZIPを解凍します。
2. sen_digit_register_iphone フォルダ内のファイルをWeb公開します。
3. iPhoneのSafariで公開URLを開きます。
4. 共有ボタン → ホーム画面に追加 を押します。
5. ホーム画面の「線数字レジ」アイコンから起動します。

フェーズ1で使える機能:
- 商品登録
- 商品写真登録
- 商品番号001〜999自動発行
- 線数字コード表示
- 商品一覧
- 3桁番号手入力
- 商品確認
- 価格だけ追加
- カート
- 支払い前明細
- 支払い方法選択
- 金額コピー
- 会計完了
- 販売済み更新
- 売上履歴
- ローカル保存
