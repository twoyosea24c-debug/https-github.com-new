線数字レジ iPhone版 Phase2-6 実運用強化版

追加内容:
- 商品一覧から商品編集
- 商品写真・価格・商品名・カテゴリ・メモ・状態の編集
- 商品一覧から販売中商品を直接レジに追加
- 売上履歴から取引取消
- 取消時に登録商品を販売中へ戻す
- 設定画面からバックアップJSON復元
- 既存の明細画像共有、線数字半自動読み取り、読み取りログ機能を継続

使い方:
1. GitHubにこのフォルダ内のファイルを上書きアップロード
2. Commit changes
3. GitHub PagesのURLをiPhone Safariで再読み込み
4. ホーム画面版を一度閉じて開き直す

注意:
決済処理そのものは外部サービスで行います。会計完了前に必ず外部決済が完了していることを確認してください。
