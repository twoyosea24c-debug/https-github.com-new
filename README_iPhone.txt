線数字レジ iPhone版 Phase2-5

この版では、線数字の半自動読み取りに「読み取り検証ログ」を追加しました。

追加内容:
- 撮影後の仮認識番号を保存
- ユーザーが修正した確定番号を保存
- 各桁の確信度を保存
- 上位候補を表示
- 読み取りログ画面を追加
- CSV書き出しに対応

目的:
現場テストで、どの数字が誤読されやすいかを確認するための版です。
例: 0が8になる、9が6になる、7と8が逆になる、など。

GitHub Pages更新手順:
1. ZIPを解凍する
2. 中のファイルをすべてGitHubリポジトリへ上書きアップロードする
3. Commit changes を押す
4. GitHub Pagesの公開URLをiPhone Safariで再読み込みする
5. ホーム画面版を完全に閉じて開き直す

アップロード対象:
- index.html
- app.js
- manifest.json
- service-worker.js
- icon-192.png
- icon-512.png
- README_iPhone.txt

テスト手順:
1. 商品を登録する
2. 商品番号の線数字を紙に書く
3. レジ画面で「線数字を読む」を押す
4. 3分割ガイドに線数字ラベルを合わせる
5. 撮影する
6. 仮認識された3桁を確認する
7. 違う桁があれば数字ボタンで修正する
8. 「この番号で商品確認」を押す
9. 読み取りログ画面で、仮認識と修正後番号を確認する
10. 必要に応じてCSVを書き出す
